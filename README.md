# Sonara
Sonara - аудиоплеер и менеджер музыкальной библиотеки для Windows. Приложение помогает организовать 
единую локальную библиотеку музыки для повседневного удобного прослушивания 

## Идея проекта
Большинство программ для управления локальной музыкальной библиотеки на компьютере либо ориентированы на профессиональных пользователей, 
вследствие чего имеют избыточный для обычного человека функционал, либо наоборот – предоставляют лишь базовый функционал, но не дают удобных 
инструментов для организации и управления своей музыкальной коллекцией. В результате пользователю, который хранит и слушает музыку локально на компьютере, 
сложно найти приложение, которое одновременно предоставляет возможности для удобной работы с библиотекой и остается простым в повседневном использовании

Sonara ориентирована на более простой и понятный пользовательский опыт и при этом 
отличается вниманием к организации и управлению локальной музыкальной библиотекой

## Тип проекта 
Desktop-приложение для Windows

## Цель и задачи
Создать удобный аудиоплеер и менеджер локальной музыкальной библиотеки для Windows, который позволит пользователю 
в одном приложении воспроизводить музыку и удобно организовывать свою коллекцию без избыточной сложности и ненужных функций

## Стек технологий
- [C#](https://learn.microsoft.com/dotnet/csharp/) / [.NET](https://dotnet.microsoft.com/): язык и платформа
- [.NET MAUI](https://learn.microsoft.com/dotnet/maui/): пользовательский интерфейс
- [NAudio](https://github.com/naudio/NAudio): аудиодвижок
- [ATL.NET](https://github.com/Zeugma440/atldotnet): чтение и запись тегов аудиофайлов
- [SQLite](https://www.sqlite.org/): хранение индекса музыкальной библиотеки
